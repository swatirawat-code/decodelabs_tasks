DecodeLabs Python Projects

Welcome to my Python Projects Repository! This repository contains three beginner-friendly Python projects developed as part of my Python programming tasks for the DecodeLabs internship.

Projects

1. To-Do List

A simple menu-driven Python application to manage daily tasks.

Features:

- Add multiple tasks separated by commas.
- View all tasks with numbering.
- Handle invalid menu inputs.
- Exit the application using the menu.

File: "todo_list.py"

How to run:

python todo_list.py

2. Expense Tracker

A console-based Python application to calculate total expenses.

Features:

- Enter multiple expenses.
- Add expenses in multiple rounds.
- Calculate and display total expenses.
- Display the total amount spent.

File: "expenses tracker.py"

How to run:

python "expenses tracker.py"

3. Random Password Generator

A Python application that generates a random password of the length specified by the user.

Features:

- Include uppercase letters.
- Include lowercase letters.
- Include numbers.
- Include special symbols.
- Allow the user to specify password length.
- Validate that the password length is positive.

File: "random_password.py"

How to run:

python random_password.py

Technologies Used

- Python 3
- Python built-in modules
- "random" module
- "string" module

Requirements

- Python 3 installed on your computer.
- A terminal or code editor to run the programs.
