# Python To-Do List

My first Python project for managing daily tasks through a simple console-based application.

## Features
- Add tasks
- View tasks with numbering
- Exit the application

## Concepts Used
- Python lists
- While loops
- If-elif-else conditions
- User input
- For loops and enumerate()

## How to Run
Make sure Python is installed, then run:

```bash
python todo_list.py
```
